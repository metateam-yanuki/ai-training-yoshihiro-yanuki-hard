# 失敗分類タクソノミー

| 分類 | 説明 | 典型的な指標 |
|------|------|------------|
| 検索ミス | 正しいドキュメントが検索されなかった | Context Recall 低い |
| 推論ミス | 検索結果はあるが LLM が誤った推論をした | Faithfulness 低い |
| 構造化失敗 | JSON 出力が壊れた・必須キーが欠損 | フォーマットエラー |
| ツール呼び出しミス | 必要なツールが呼ばれなかった・引数が間違っている | タスク達成率 低い |

## 記入方法
Day11 の評価結果を見て、各失敗ケースをこの4分類に当てはめて原因を考察してください。
