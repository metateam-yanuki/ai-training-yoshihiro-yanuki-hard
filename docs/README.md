# docs

このディレクトリには、最終課題の設計メモや評価結果を格納します。

## 格納するドキュメント（受講者が作成）

### 1. 状態遷移図

LangGraphの状態遷移を図示したファイル（例: `state-diagram.md` or `state-diagram.png`）

記載内容：
- stateの定義（保持する変数）
- ノードの一覧と役割
- エッジの条件
- サブグラフとの関係

### 2. 主要プロンプト

エージェントで使用するプロンプトの設計メモ（例: `prompts.md`）

記載内容：
- Supervisor システムプロンプト
- research Worker プロンプト
- summarize Worker プロンプト
- LLM-as-a-Judge 評価プロンプト

### 3. システム構成

システム全体の構成図（例: `architecture.md`）

記載内容：
- A2A サーバーの役割と公開エージェント
- MCP サーバーの役割と公開ツール
- メモリバックエンド（SQLite DB）の管理方法
- ログファイルの管理

### 4. 失敗パターンと対策

想定する失敗パターンと対策のメモ（例: `failure-patterns.md`）

記載内容：
- failure_taxonomy.md の4分類への当てはめ
- 各失敗パターンへの改善策
- 回帰テストの結果

### 5. 評価結果と改善ログ

テスト実行の結果と改善履歴（例: `evaluation.md`）

記載内容：
- Day11 の評価スコア（初期）
- Day12 の改善後スコア
- 改善前後の比較表
- 残課題・次のアクション
